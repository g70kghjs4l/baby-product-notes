# HPV疫苗

> 更新时间：2026-09-16 (UTC+8)

HPV（人乳头瘤病毒）——宫颈癌的元凶。

 
 

高危型导致宫颈癌前病变和宫颈癌 

 低危型病毒主要和生殖器官的尖锐湿疣有关系。

 谈到HPV病毒首先想到的是宫颈癌，事实上HPV和很多恶性肿瘤有关：阴茎癌、肛门癌、外阴癌、口腔癌、喉癌等等。
 
 宫颈癌的一级预防——HPV疫苗
2013年之前全球有两种人类乳头瘤状病毒(HPV)疫苗上市，分别是默沙东(Merck)药厂研制的加卫苗(Gardasil)，以及葛兰素史克(GlaxoSmithKline）的2合1卉妍康疫苗(CervarixTM)。
 

 卉妍康2合1疫苗相当于加卫2合1疫苗，只覆盖16、18型HPV。

 美国食品药品监督管理局（FDA）2014年12月10日在其官网宣布：默沙东（在美国和加拿大称为默克）研发的GARDASIL9（佳达修，九价重组人乳头状瘤病毒疫苗）获批。

**预防约90%的宫颈癌及相关癌症**

GARDASIL9批准适用于9至26岁的女性和9至15岁的男性，以预防HPV病毒（人乳头状瘤病毒）16、18、31、33、45、52 和58型引起的宫颈癌、外阴癌、阴道癌和肛门癌，以及人乳头状瘤病毒6和11型引起的生殖器疣。

新疫苗有潜力预防约90%的宫颈癌、外阴癌、阴道癌和肛门癌。

**覆盖更多HPV病毒**

相较于第一代GARDASIL疫苗，GARDASIL9增加了31、33、45、52 和 58五种病毒亚型，这些病毒引起了约20%的宫颈癌，是此前FDA获批的HPV病毒疫苗所不能预防的。

能够预防90%的宫颈癌，当然是女性的福音，但遗憾的是，HPV已经获批在美国及欧洲上市，并在全球推广，而中国的广大女性仍然无法很便捷获得这个疫苗。

无论4价疫苗还是九价疫苗，注射后都不能100%预防宫颈癌，因此即便你能够去香港、美国注射HPV疫苗，注射后定期的宫颈涂片--TCT 检查和HPV检查仍然是必须的。
