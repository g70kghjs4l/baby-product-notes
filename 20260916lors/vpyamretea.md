# 【专家贴士】吓人！一夜鼾声中断232次！

> 更新时间：2026-09-16 (UTC+8)

**吓人！一夜鼾声中断232次！**
  
他睡觉会打鼾，有时一口气没接上来，然后被憋醒，这是病吗？你可别小瞧这种经历，其实它是“睡眠呼吸暂停综合征”的典型表现，重则可能因长期缺氧带来多种疾病，甚至威胁生命。 

小严（化名）42岁，是名搬运工，到省级医院睡眠呼吸疾病诊治中心做睡眠监测，结果显示，他入睡7小时，呼吸暂停了232次，最长暂停时间78秒，缺氧时间(血氧饱和度小于90%)4.5小时，最低血氧56%。这说明他的呼吸暂停非常严重，结合其他症状确诊小严患有睡眠呼吸暂停综合征，来我院经过治疗，他所患的高血压、肾病、甲亢，都与打鼾有关。经过治疗，小严重精神多了，血压也有了改善。

鼾声过大有时候是睡眠呼吸暂停综合症的一种表现，只是很多朋友没觉得打鼾也是病。　

**什么是睡眠呼吸暂停综合征？**
  
睡眠呼吸暂停综合症是睡眠期间反复出现的、短暂的、可逆的上呼吸道狭窄或阻塞，引起呼吸暂停或低通气，有时伴有喊鼾声，引起日间过度嗜睡表现的一组症候群。

博爱医院副主任医师李正民告诉大家，通俗地说，睡眠呼吸暂停就是在睡眠时发生的呼吸暂时停顿的现象。呼吸暂停的定义是，口和鼻气流停止10秒以上为一次呼吸暂停，在一夜7个小时的睡眠中，呼吸暂停发生30次以上或睡眠呼吸紊乱指数超过5次以上，如果有白天有乏力、嗜睡等症状，就是阻塞性睡眠呼吸暂停综合征。

**有什么危害？如何治疗？**
  
睡眠呼吸暂停可引起慢性间歇低氧、二氧化碳潴留、胸腔负压增大等，在此基础上引发自主神经功能紊乱及炎症反应，血管内皮细胞损伤，血液黏度增高，高凝状态、纤溶系统异常等，导致许多“泥沙”在血管中堆积，诱发动脉粥样硬化，出现高血压、冠心病。

**长期的睡眠呼吸暂停还会造成下面的影响，需要到大医院进行规范治疗。**

1、性格变化：包括急躁、压抑、精神错乱、幻觉、极度敏感、敌视、好动，易发生行为失当、嫉妒、猜疑、焦虑沮丧等;

2、智力和记忆力减退、思维迟钝以及性功能障碍等;

3、白天疲倦、嗜睡、头晕头痛和工作状态不佳；

4、导致高血压、肺动脉高压、冠心病、心肌梗死、肺心病、中风、老年痴呆等，还能增加睡眠过程中猝死危险;

5、胃肠道疾病：阻塞性呼吸障碍可引起胸腔负压增加，导致食道返流，使胃肠道疾病久治不愈;

6、夜尿多：缺氧还会引起肾小管回吸收功能障碍，夜尿增多;

**如何正确诊断呢？**
  
多导睡眠图(PSG)虽然是诊断睡眠呼吸暂停综合征的金标准，但由于需要住院，导致费用增高以及医院病床有限，无法对广大人群进行大面积筛选。

我院新引进“睡眠呼吸暂停监测动态记录仪”，该检测无需病人住院留观，只须将仪器安放在被查者身上，进行日常的工作和睡眠，就可以准确地记录和监测睡眠情况。

该检查仪内设高达10位的呼吸波采集系统，每晚22：00自动开启，早晨6：00结束，可放大察看呼吸波形、体位等，进行呼吸波与动态心电波形的同步对比进行分析，用于更高精度的睡眠呼吸暂停综合症的普筛。是一种非常便捷方式，较多导睡眠图(PSG)更适合大量人群进行睡眠呼吸暂停综合征的普筛。

**什么时候该看医生呢？**
  
1、尽管睡了一整夜，醒来仍然感到十分乏力。 

2、夜间反复憋醒，夜眠不宁，不自主翻动，甚至昏迷抽搐。 

3、打鼾突然停止（一般为数秒至数十秒）后，鼾声又起。 

4、醒后头痛，睡醒起床后口干舌燥。 

5、白天非常困倦或者打盹，甚至在工作或驾驶时睡着。

6、暴躁易怒，睡醒血压更高。

7、注意力不易集中或记忆力下降。 

8、不明原因的夜间睡觉时小便次数增加。 

9、阳痿、性欲减低。
